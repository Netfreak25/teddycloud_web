# Translation sources

## Klingon (`tlh`)

The Klingon UI vocabulary is intentionally maintained as a partial translation.
Long technical descriptions fall back to English instead of being machine-translated.

The curated vocabulary is based on:

- Google Blockly's manually maintained Klingon localization and its Klingon
  translation guidance: <https://docs.blockly.com/guides/contribute/core/klingon/>
- Klingonska Akademien's human-maintained Klingon Pocket Dictionary:
  <https://klingonska.org/dict/>

Klingonska Akademien's dictionary data is licensed under
[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). This project
attributes Klingonska Akademien and links to the original dictionary as required.
